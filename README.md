# Flask Calculator

A simple web-based calculator application built using **Python and Flask**, with HTML, CSS, and JavaScript for the frontend.

## Features

- Simple and user-friendly interface
- Addition, subtraction, multiplication, and division
- Responsive web page
- Flask backend
- HTML and CSS frontend

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/akbar-va/flask-calculaor.git
```

### 2. Navigate to the project folder

```bash
cd flask-calculaor
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate virtual environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open in browser

Visit:

http://127.0.0.1:5000

## Run Tests

```bash
python -m pytest
```
